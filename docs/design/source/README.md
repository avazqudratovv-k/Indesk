# Indesk design source (from the FINAL DESIGN PROJECT 2 canvas)

- source/*.dc.html : the exact markup and CSS of every board (desktop and Mobile ones end in M).
- source/canvas.json : board sizes and titles.
- assets/ : the image files the boards load as /_blob/<id>. File name = the id.
- assets-usage.txt : which board uses which asset.

Boards need the canvas runtime (support.js) to render alone. Read them as CSS/markup reference, not as pages to open.
